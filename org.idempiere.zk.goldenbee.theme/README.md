# Goldenbee Theme for iDempiere

This is a custom theme for iDempiere, based on the Breeze theme.

## How It Was Created

This theme was generated by performing the following steps:
1. Copying the `org.idempiere.zk.breeze.theme` directory.
2. Renaming the internal project files (like `.iml`).
3. Updating project configuration files (`pom.xml`, `META-INF/MANIFEST.MF`, `*.zul`, `lang-addon.xml`) to replace all instances of the "breeze" theme with "goldenbee".

## How to Customize

- **Styles (CSS):** To customize the look and feel, edit the CSS files located in `src/web/theme/default/css/`. The primary file for style changes is `theme.css.dsp`.
- **Images:** To change images, you can replace the files in the `src/web/theme/default/images/` directory.

## How to Build and Deploy

To include this theme in the main project build, follow these steps:

1. **Add to Build:** Add this theme as a module in the root `pom.xml` file of the `idempiere-theme` project. To do this, add the following line inside the `<modules>` section:
   ```xml
   <module>org.idempiere.zk.goldenbee.theme</module>
   ```

2. **Build the Project:** From the root directory of the `idempiere-theme` project, run the following command. This will build all modules, including your new theme.
   ```sh
   ./mvnw clean install
   ```

3. **Deploy:** After a successful build, the theme will be available as an OSGi bundle in the target platform. You can then install and activate it within your iDempiere instance.
